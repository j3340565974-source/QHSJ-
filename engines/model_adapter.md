# 模型适配引擎（MDA）

> 用途：把内部统一的富结构提示词编译为具体模型可接受的图片/视频请求。所有模型能力来自用户配置与源资料声明；未验证能力必须标注 `unknown`，禁止虚报。

## MDA-01 模型档案来源

- 用户开工确认单中的模型选择（最高优先级）。
- 资料默认历史值：图片 `Seedream 5.0 Flash`（源文拼写 fash 已规范化；摘要中的 Seedream 4.0 降级为历史值），视频 `Seedance 2.0`，豆包平台默认 `Seedance 2.0 Fast`，Pavo 平台图片 `Agnes image 2.5 Flash` / 视频 `Agnes Video 2.5`。
- 平台 API 文档与实测结果（标记获取时间）。

## MDA-02 图片编译

- 富结构 AST → 单镜生成 prompt 或多镜制作母版；单镜 payload 以 Camera 描述开头。
- 输出字段：正向、负向、画幅、生成尺寸、步长、参考图引用（可选）、seed（可选）。
- 生成档 0.8–1.8MP；尺寸满足模型步长，无特殊要求时取 8 的倍数；交付档 2K/4K/6K 另行放大/重采样。
- 卡面文字律：制作参数只进几何/镜头/画质段，不印在卡面上；卡面文字只写内容信息。

## MDA-03 视频编译

- 时长档：以目标模型文档为准，未知时按用户配置；不得把 3s/5s/10s 剪辑镜头误当全部镜头统一模型档。
- 生成时长 vs 剪辑时长分离：`editorial_duration` 校验零缝隙，`generation_segments` 只校验模型档。
- 图生视频/文生视频通道分开；首帧来自故事板/资产且必须登记为已验收资产。

## MDA-04 词数与结构

- 角色设定卡正文默认上限 1900 字符（源文 1800 与九段预算 1830 冲突的最终裁决）；模型另有硬限制时先裁示例再保九段锚点，禁止删除主体、机位、负向与画幅字段。
- 负向词按 L6 主媒介与卡种从 `shared/negative_words.md` 动态装配，不整库粘贴。
- 情绪等抽象字段作为内部元数据，不直接喂给不支持该语法的模型。

## MDA-05 资产引用与一致性

- 图片/视频同风格同质感：图片阶段确定的质感、画风、色彩系统，视频阶段逐字沿用（`{{CHAR_LOOK}}` 等变量）。
- 参考图默认不作为图生图输入；用户显式要求时登记用途（风格参考/结构参考/重绘底图）。

## MDA-06 校验

`scripts/validate_prompt.py` 校验：模型档字段、词数预算、负向装配来源、资产引用登记、比例与作用域一致性。
