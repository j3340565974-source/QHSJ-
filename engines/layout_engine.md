# 版式求解引擎（LAY）

> 用途：全部卡种与故事板的几何、面积、网格、边距统一计算。本文件是唯一几何事实源；参考图只作结构证据，不作像素真值（`assets/INDEX.md`）。

## LAY-01 画幅作用域

| 作用域 | 符号 | 说明 |
|---|---|---|
| 项目成片 | `project_aspect` | 由用户指定，短剧默认 9:16 竖屏、电影感默认 16:9 |
| 资产卡面 | `asset_canvas_aspect` | 卡种默认 16:9，可按内容改 21:9/9:16 等 |
| 镜格 | `cell_aspect` | 由网格公式反推，不固定 16:9 |
| 全景 | `panorama_aspect` | 固定 2:1（equirectangular） |

各作用域独立校验，禁止跨层强迫同值。

## LAY-02 网格公式（替代照表）

```
canvas_r = canvas_w / canvas_h
cell_r = canvas_r * rows / columns        # 无间距精确式
cell_r = canvas_r * rows / columns        # 有间距时以间距预算修正，见 LAY-04
```

- G4=2×2、G6=3×2/2×3、G8=4×2、G9=3×3、G12=4×3/6×2。
- 镜号从左到右、从上到下。
- 故事板默认 `G9_NO_BLANK`：九格全填、无装饰性外留白、无空格；必要镜号与分隔线不算留白。

## LAY-03 面积与配比

- 纵向：标题 5% + 内容区 88% + 底部 7% = 100%；纯文字区合计 ≤12%。
- 内容区内板块配比必须归一化（合计 100%），由 `scripts/validate_layout.py` 校验；废止全局“主图恒 46%”与未归一化的 34/38/28 硬常量。
- 主视觉板块为全卡最大单一板块；具体面积按卡种模板用 W×H 实算。

## LAY-04 边距与间距（五种字段，禁止混用）

| 字段 | 默认 | 说明 |
|---|---|---|
| `outer_margin` | ≤1.5% | 卡面外边界 |
| `module_gap` | 短边×1.5% | 模块间距 |
| `inner_padding` | 按模板 | 格内物体余量 |
| `artistic_negative_space` | 按风格 | 水墨等艺术留白合法 |
| `empty_cell` | 禁止（故事板） | 镜格不得空白 |

旧“安全边距=短边2%”废止；服装细节格四周余量 8%–10% 属于 `inner_padding`。

## LAY-05 服装卡几何（唯一现行版）

- 一个 1:1 正方形区域，竖向三等分为三个 1:3 竖条（正/侧/背）。
- 右侧剩余空间 2×2 细节格；长条细节可横向合并；底部 8%H 工具条。
- 16:9 下主体区：左约 50%W×86%H，右约 46%W×86%H。
- 旧“三个 1:1 格、三格各 30%W”全部废止。

## LAY-06 道具卡几何

- `object.elongation_r = max(w,h) / min(w,h)`；R≥3 长条（横向三层），1≤R<3 团块（居中+右侧多视图），薄片另判厚度。
- 与 `material.reflectance_r`、`geometry.aspect_r` 命名空间隔离。
- 资产格最小宽 ≥ 短边×14%；格数 `N = clamp(round(带宽 / (短边×19%)), 6, 12)`，场景卡竖版资产带按 6×2 理解。

## LAY-07 外景全景

- 基底：水平 360°×垂直 180°、2:1 equirectangular；“720°”只作产品名。
- 卡面 16:9：全景条约占卡宽 54%，左右各约 20.5%W 竖细节，下排 5 横细节，标题 6%H。
- 细节图通过等距圆柱→透视投影转换，不得按平面矩形直接裁剪。

## LAY-08 生成像素

- 生成档：0.8–1.8MP，尺寸满足模型步长（无特殊要求时取 8 的倍数）；交付档 2K/4K/6K 按项目选择。
- 候选像素必须输出实际比例与误差，禁止把近似尺寸写成严格等比；交付时不引用参考图像素（如 2100×1050）。

## LAY-09 校验

所有版式输出必须过 `scripts/validate_layout.py`：画幅作用域、网格公式、面积归一、边距字段、服装 1:1→1:3、故事板空格、全景定义。
