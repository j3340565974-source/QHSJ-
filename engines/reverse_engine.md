# 反推引擎（REV）

> 用途：从图片/成片/文字描述反推镜头、风格、光影、构图与提示词。只读分析：不得直接修改项目台账，输出须经用户确认或人工登记后由对应模块消费。

## REV-01 三条反推路线

| 路线 | 输入 | 输出 |
|---|---|---|
| R1 镜头优先 | 图片/视频片段 | 景别、机位、运镜、构图、轴线（→ CAM） |
| R2 风格抽取 | 参考图/成片风格 | 六层风格 + 八维参数（→ `shared/aesthetic_system.md`） |
| R3 1:1 目标 | 用户指定目标样张 | 差距清单与逐项复制性评估 |

## REV-02 证据链

每个结论必须携带：
1. 证据（画面中的具体特征，如高光位置、透视灭点、色彩分布）。
2. 置信度：`high`（可直接采用）/ `medium`（需复核或组合）/ `low`（仅参考）。
3. 无法判定时输出 `unknown`，禁止用“可能是”当作确定值。

## REV-03 置信度门槛

- `high` 才可进入项目参数默认值；`medium` 必须列出 2 个以上交叉证据或请求用户确认；`low` 不写入台账。
- 版权与在世艺术家风格：仅做通用特征分解，不产出直接模仿性提示词；用户提供的私有参考不受此限但需声明授权。

## REV-04 反推范围

- 镜头：主体占比→景别；灭点/地平线→机位与高度；运动模糊与连续帧→运镜与速度；越轴判断→轴线说明。
- 光影：高光/阴影方向、软硬、光比、色温、环境光；人像可推断伦勃朗/蝴蝶/三点等预设。
- 色彩：主色调、互补/三色、饱和明度，输出 hex 仅进内部参数层，不直接进角色最终提示词（遵循卡面文字律）。
- 材质：反射/粗糙/做旧，映射 M1–M6 或八维 L7。

## REV-05 与生成约束的冲突处理

- 反推结果不得覆盖 `shared/standard_specs.md` 的硬约束（画幅作用域、网格公式、安全性）。
- 反推样式与用户风格要求冲突时，按安全＞用户显式变更＞剧本事实＞连续性台账＞模板默认裁决；仍需用户确认时进入 HITL 暂停，不静默覆盖。

## REV-06 输出契约

输出 JSON 结构：`evidence[]`、`conclusions[]`、`confidence[]`、`unknowns[]`、`consumers[]`（目标模块）。`scripts/validate_prompt.py` 校验字段完整性与路由合法性。
