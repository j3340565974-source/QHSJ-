# 镜头与运镜引擎（CAM）

> 用途：为剧本、分镜、资产卡、故事板和视频提示词统一提供景别、机位、构图、运镜与轴线规则。被 `shared/aesthetic_system.md` 的运镜设计入口调用；本文件不负责风格参数与提示词装配。

## CAM-01 术语唯一性

- **景别**：由主体在画框中的占比决定，同一镜头只能有一个主景别，可在运镜中渐变（如 WS→MS）。
- **机位**：相机相对主体的方位、高度与距离。
- **运镜**：机位或镜头参数随时间的变化。
- **画幅作用域**：`project_aspect`（成片）、`asset_canvas_aspect`（卡面）、`cell_aspect`（镜格）互不混用，见 `shared/standard_specs.md`。

| 代码 | 景别 | 判定基线 |

| EWS | 远景 | 人物为环境中元素 |
| OTS | 过肩 | 带前景肩部 |

## CAM-03 构图库与视觉锚点

1. 三分法、中心、对称、对角线、框架、引导线、负空间、层次前景遮挡。
2. 前中远三层：前景遮挡物必须说明材质与焦点（焦外），不得写“某个前景”。
3. 主体与背景亮度、色彩、明度差是可校验的软约束；`asset_neutral` 白底资产与 `technical_diagram` 技术图豁免对比度硬门槛（见 `shared/aesthetic_system.md`）。

## CAM-04 运镜规则

- **一个主运镜 + 可选辅助效果**：静态（static）不得与位移类运镜同时声明；辅助只允许光学/时间类（变焦、焦点转移、慢镜、手持微震、呼吸感），且必须标注主次。
- 运镜三段式：`起始状态 → 运动方式与方向 → 落幅`，禁止只写“推进”“摇”而无落幅。
- 速度量化：升格/降格必须写 fps 与起止秒点；一段内速度变化 ≤3 次；禁止写“突然”“瞬间”替代精确秒点。

## CAM-05 屏幕方向与 180° 轴线

- `screen_angle = normalize(character_facing - camera_view_direction + 180°)`，其中 `camera_view_direction` 为相机指向主体的方向，结果 0°=正对镜头、180°=背对镜头。
- 对话/对峙保持 180° 轴线；越轴必须写明理由（中性镜头、主动越轴动机、重新定场）。
- 空间关系卡（方位卡）四视图由同一布局派生，机位高度、焦段、光位、时间一致。

## CAM-06 情绪到镜头

- 输入情绪与节奏强度，输出：景别序列、运镜节奏、镜头时长倾向、手持/稳定、光比倾向。
- 情绪越平镜头越少越长；情绪越烈镜头越多越短；但快切连续不超过 8 镜，快切后必须接长镜（`validate_duration.py` 校验）。

## CAM-07 资产卡机位

| 卡种 | 默认焦段/机位 |
|---|---|
| 人物设定卡主视觉 | 85mm 胸像，头约占板块高 40% |
| 人物全身三视图 | 85mm，全身占格高 95%，三格等高同比例 |
| 服装人台三视图 | 85mm，人台占格高约 92% |
| 道具 | 主体同源等比；细节 50–100mm 微距 |
| 场景 HERO | 广角中景，前中远三层，中央预留调度区 |
| 内景方位 | 0°/90°/180°/270° 中轴四方位 + P03 布局锚点 |
| 外景全景 | 2:1 equirectangular 360°×180°，非透视裁片 |

## CAM-08 输出契约

所有镜头描述必须可被 `scripts/validate_prompt.py` 解析：包含景别、机位方向、主运镜、落幅、可选辅助与理由；缺少任何一项不得进入生成提示词。
