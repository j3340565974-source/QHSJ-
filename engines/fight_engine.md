# 打斗引擎（FIG）

> 用途：打斗/动作场景的镜头设计、动作链、受击链、安全分级与节奏。按需加载，不搭售；输出进入 `modules/02_storyboard.md` 与 `modules/08_video_prompt.md`。

## FIG-01 动作分类（先分类再设计）

| 类别 | 判定 | 处理 |
|---|---|---|
| MOVE | 位移动作（跑、跃、滑步） | 写轨迹、速度、接触面 |
| IMPACT | 真实击打（命中人/物） | 必须写受击链 FIG-03 |
| BENIGN | 良性接触（搭肩、扶、拥抱、格挡） | 禁止写成伤害链 |
| OBJECT | 物件动作（持械、投掷、破坏） | 道具台账挂载，去向可追踪 |
| STATE | 姿态/状态（倒地、眩晕、受限） | 进入 `shared/context_ledger.md` 状态增量 |

## FIG-02 动作链与关节链

- 每个连续动作写全链条：`蓄力 → 发力 → 命中/顶点 → 卸力 → 收势`。
- 关节链顺序：根节（腰/肩）→ 中间（肘/膝）→ 末端（拳/脚/刃），违反生物力学必须给出超现实设定依据。
- 动作与站位、朝向、持械手在每镜中一致；双手占用由连续性引擎校验（不可同时插袋与持物）。

## FIG-03 受击链与环境反馈

1. 命中点（身体部位/物件部位）。
2. 力方向与量级（轻/中/重，重击必须后果）。
3. 被击者反应：位移、姿态、表情、后续能力衰减。
4. 环境反馈：声响、扬尘、碎屑、振动、道具位移。
5. 后果登记：伤痕、武器掉落、倒地状态写入台账，下游镜号生效。

## FIG-04 安全分级（家庭友好默认）

| 级别 | 允许内容 |
|---|---|
| G1 安全 | 冲击省略或示意，无见血、无致命 |
| G2 中度 | 瘀伤、擦伤，血量≤轻度，不特写伤口 |
| G3 强对抗 | 见血可特写，但致命打击必须淡化或遮挡 |
| G4 极端 | 仅在用户显式要求并符合平台限制时启用 |

默认 G1；`shared/negative_words.md` 按级别输出对应负向。

## FIG-05 节奏与镜头

- 节奏骨架：`建立 → 接触 → 发力 → 转换 → 高潮 → 结果`，节点数可变，节点顺序不可变。
- 快切段连续 ≤8 镜，快切后接长镜；升格只在打击顶点/受身使用，全片变速总时长 ≤30%。
- 每个关键帧只来自剧本/分镜提取源，禁止脑补招式之外的剧情（`modules/07_storyboard_gen.md`）。

## FIG-06 风格接入

打斗提示词必须调用 `shared/aesthetic_system.md` 的 `cinematic` profile 与 CAM 运镜设计；材质档由故事板 M1–M4 决定，与打斗逻辑解耦。

## FIG-07 校验

- 每一 IMPACT 必须能回溯受击链五项。
- 每一 STATE 必须能在台账找到增量与重置记录。
- 输出交给 `scripts/validate_workflow.py`（分类完整）与 `scripts/validate_duration.py`（节奏量化）。
