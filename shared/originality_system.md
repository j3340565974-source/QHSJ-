# 原创设计系统（originality_system）

> 微内核共享服务。本文件是九类原创设计路由、原创三不与内部物理自洽的唯一事实源。规则 ID 前缀 `ORI-`。非原创意图不加载本文件；按需加载、不搭售是本系统的第一原则。

## 1. 路由总则（ORI-01）

- ORI-01-1 固定九类原创板块：人物、生物、服装、场景、命名、武器、特效、文案、配音/BGM。板块数量与名称不得增删改（原文"八板块/九板块"混写已废止）。
- ORI-01-2 仅当用户点名"原创、独特、创新、创意、灵感"等关键词并指向某一设计对象时，才路由到对应板块；组合需求按点名板块组合输出。
- ORI-01-3 禁止搭售：要原创人物只出人物板块，禁止一次性输出全部九板块；单点需求只交付单点。
- ORI-01-4 三态触发：用户给了该板块具象要求 → 优先用用户内容；用户只给题材/风格/情绪 → 基于题材自动生成；完全未指定 → 全自动生成并标注"以下设计为系统原创"。
- ORI-01-5 变量值从剧本与题材推导，不从预设列表选择；选项库是"曾经出现过的值"，不是"只能选这些值"。

## 2. 九类路由与落位（ORI-02）

| 板块 | 触发词示例 | 设计架构 | 完成后落位 |
|---|---|---|---|
| 人物 | 原创人物 / 独特角色 / 创新人设 | 五层：骨相 → 皮相 → 五官 → 毛发 → 饰与型 | 角色锚点卡（`../modules/03_asset_character.md`），走资产图流程 |
| 生物 | 原创生物 / 独特怪兽 | 六层：形态 → 体表 → 感官 → 运动 → 能力 → 生态 | 资产图流程（道具/资产）；受击反馈复用打斗引擎 |
| 服装 | 原创服装 / 独特造型 | 五模式融合：文化对撞、时代拼贴、材质杂交、廓形重构、符号转译（选 2–3 种） | 角色锚点卡服装锁定字段，走 `../modules/05_asset_costume.md` |
| 场景 | 原创场景 / 独特世界观 | 五层空间：近景门槛 → 承人界面 → 统治主体 → 从属空间 → 天际终点 | `../modules/04_asset_scene.md` + 场景锚点卡（`context_ledger.md`） |
| 命名 | 原创名字 / 起名 | 三段种子：类型相关片段 A+B+C 组合 | 定稿登记台账（`context_ledger.md`） |
| 武器 | 原创武器 / 独特兵器 | 类型、材质、锻造、能量属性、形态特征、文化母题 | `../modules/06_asset_prop.md`；接触物理守红线 |
| 特效 | 原创特效 / 能量设计 | 能量类型、粒子形态、光影、色彩、动态、环境反馈、音效 | 对应视频引擎（`../modules/08_video_prompt.md`） |
| 文案 | 原创文案 / 台词润色 / 古风用词 | 对白、旁白、场景描写、命名用词按古典来源分层取用 | 对应文字交付物；现代题材不强制古化 |
| 配音/BGM | 原创配音 / 角色音色 / BGM | 配音五要素（基调、语速、情感层、共鸣、气息）；BGM 五要素（曲风、情绪曲线、乐器、节奏、时长） | 配音五要素写入角色锚点卡音色锚点；BGM 与分镜节奏对齐 |

- ORI-02-1 设计完成后必须落位衔接（见上表右列），原创设计不是孤立交付物。
- ORI-02-2 每个原创设计完成后输出三件套：设计卡（人类可读方案）、图片提示词（按 `standard_specs.md` 总装与目标平台转换）、视频一致性锚点（接资产还原声明）。

## 3. 原创三不（ORI-03，全板块通用）

1. 不复制已有作品中的角色名、称号、专有物种名、专有饰品名。
2. 不简单拼贴已有角色/生物的外貌形态元素。
3. 每个设计都要有文化依据或生态依据，且物理可验证。

去重校验：与已有作品专有名词比对，检查命名逻辑（五行/道家/诗词/音韵）是否自洽。有联网能力时执行全网比对；无联网时仅做内部逻辑校验 + 与本项目已用名比对，并注明"去重降级：仅内部校验"。

## 4. 内部物理自洽（ORI-04）

- ORI-04-1 约束配对：每个强大能力必配代价与弱点（能量来源、冷却条件、特定环境依赖、核心暴露等）。
- ORI-04-2 环境推导：生物形态由栖息环境推导（深海/洞穴/高重力/无氧等）；外星生物按外星环境而非地球生物逻辑推导。
- ORI-04-3 物理恒量：重力 9.81m/s²、动量守恒、表面张力等在本系统产出的动作与特效描述中不可违背；碎屑走抛物线，倒地带重量感。
- ORI-04-4 描述形态而不描述物种名：不借用现成物种名定义原创生物，用形态、质感、氛围三要素书写。
- ORI-04-5 有机与机械融合体要体现"生长感"而非"制造感"。
- ORI-04-6 巨物类尺度证据至少四项：人物占画面高度 1%–4%、柱径与人物比 ≥1:10、巨物局部超画幅、天际三层以上递减；禁止巨物全身入画、禁止人与巨物同框正面对视。

## 5. 设计纪律（ORI-05）

- ORI-05-1 每个原创人物必须有一个辨识度锚点（独特记忆点：泪痣、断眉、朱砂、固定配饰等）；气质决定五官走向；文化母题从山海经、敦煌、宋瓷、水墨、青铜器等体系提取。
- ORI-05-2 造型随角色弧光演变（初始/觉醒/堕落/重生四态可选），但辨识度锚点跨态不变。
- ORI-05-3 命名支持八类（角色/功法/门派/物品/灵兽/地点/丹药/道号）与七级稀有度（凡品/良品/上品/极品/秘宝/灵宝/古宝），组合后必须过 ORI-03 三不校验再定稿。
- ORI-05-4 原创设计的图片提示词仍须过 `aesthetic_system.md`（含 profile 选择与六层风格公式）与运镜设计；设计公式只替换风格参数，不改变依赖与校验流程。
- ORI-05-5 本系统产出的提示词负向按 `negative_words.md` 意图层动态生成。
