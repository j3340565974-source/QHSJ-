# shared/negative_words.md — 负向词装配服务（动态白名单）

> Skill v1.5.2 共享服务。负向词按【媒介 × 卡种 × 意图】动态装配，禁止整库粘贴；白名单优先于黑名单，命中白名单的条目必须有理由记录。

## NEG-01 四层装配

| 层 | 内容 |
|---|---|
| L1 通用 | 乱码文字、水印、残缺肢体、多余手指、非预期模糊/过曝 |
| L2 媒介 | 按 L6 主媒介互斥词（写实→无 3D 塑料感；3D→无 doll face 等） |
| L3 卡种 | 故事板材质档负向、服装 M6 负向、角色卡解剖负向 |
| L4 意图 | 由用户约束与安全分级（FIG-04）衍生 |

## NEG-02 通用负向（默认基线）

`无乱码文字、无水印、无多余手指、无残缺肢体、无过度渲染、无未替换变量 {{}}`

## NEG-03 媒介负向（节选）

- 写实实拍类：`无 3D 塑料感、无油画感`
- 次世代/3D 类：`无 doll face、无 overly smooth skin`（人偶肤质需求时剔除）
- 赛璐璐/三渲二：`无厚涂质感、无照片级细节`
- 水彩：`无油彩厚堆、无硬边阴影`
- 像素/体素：`无高清写实细节`

## NEG-04 卡种负向（节选）

- 故事板 M1/M2：`无写实材质、无彩色、无面部五官、无文字乱码、无水印、无过度渲染`
- M3 线稿：`无明暗调子、无灰度、无阴影、无彩色、无写实材质`
- M4 灰白写实：`无彩色、无乱码文字、无水印、无过度渲染、无油画感、无插画感`
- 服装 M6：`无头发、无妆容、无五官、无头饰、无肤色`（“人台”本身不禁止）
- 角色卡：`无多余手指、无关节错位`（禁多指，不禁正常手部）

## NEG-05 意图白名单（白名单优先）

| 白名单条目 | 生效场景 |
|---|---|
| 硬字幕/标题/旁白字幕 | 用户明确要求、故事板镜号标注、成片压字（AUD-07） |
| 度数符号（0°/90°/180°/270°） | 内景方位卡方位标注 |
| 人台/白膜 | 服装卡 M6 |
| 留白/留空 | 水墨等艺术风格（`artistic_negative_space`） |
| 运动模糊/残影 | 速度表现镜头（SPC-02） |
| 血量（按安全分级） | FIG-04 G2 以上且有剧情必要 |
| 场景内道具文字（招牌/证件/书页） | 与剧情相关且拼写正确 |

## NEG-06 禁止的全局禁令

以下条目**不得**作为全局负向（曾导致跨卡冲突，已废止）：
- 禁止一切“留白/留空”（与水墨、服装人台余量、缓拉留白冲突）；
- 禁止一切“人台/去头”（与服装卡冲突）；
- 禁止一切“度数符号”（与方位卡冲突）；
- 禁止一切“文字/字幕”（与故事板镜号、硬字幕冲突）；
- 禁止一切“模糊”（与运动模糊、浅景深冲突）。

## NEG-07 冲突裁决与校验

- 同一意图同时命中黑名单与白名单：白名单生效并记录理由。
- 正负向互相矛盾时按优先级链裁决（SP-01）。
- `scripts/validate_prompt.py` 校验：负向装配必须声明来源（本文件规则 ID），白名单命中必须带 `reason`。
